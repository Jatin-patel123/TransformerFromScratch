# TransformerFromScratch

This repository is primarily for my personal practice purposes, but it also serves as a great resource for anyone looking to understand the fundamentals of Transformers.

## Overview

This project aims to explain the Transformer architecture in basic, easy-to-understand terms. To truly grasp how these models are built from the ground up, I have created mini versions of two of the most influential Transformer-based models:

*   **Mini GPT**: A scaled-down version of the Generative Pre-trained Transformer to understand auto-regressive language modeling and decoder-only architectures.
*   **Mini BERT**: A scaled-down version of Bidirectional Encoder Representations from Transformers to understand masked language modeling and encoder-only architectures.

By building these models from scratch, this repository provides hands-on insights into the core components of modern NLP models, such as self-attention mechanisms, positional encoding, and feed-forward networks.
